# Solana Sniper Bot: Behavioral Reverse-Engineering

This repository contains the complete implementation, analysis, and final submission notebook for the Solana Sniper Reverse-Engineering competition.

## Project Structure
- `notebook/`: The final Kaggle submission notebook (`solana_sniper_bot_replica.ipynb`).
- `results/`: Contains the generated figures, tables, and metrics supporting the analysis.
- `src/`: Modularized source code for data processing, feature engineering, modeling, replay, and validation.
- `Kaggle_Writeup.md`: The detailed scientific narrative accompanying the submission.

## Requirements
Please see `requirements.txt` for the exact library versions used to produce these results.
